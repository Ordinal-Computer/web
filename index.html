Common questions

Still curious? Write to the team. A human reads every message.

What is Ordinal?

Ordinal runs your heaviest commands on a fleet of cloud machines. Put ordinal in front of the command you were already about to run; it ships the work out, streams progress back, and writes the results into your folder as if the run were local. Renders, exports, builds, and tests are what it’s built for.

Is this just a render farm?

A render farm is a place. You package a job, upload it, wait in a queue, download the result. Ordinal is a prefix. No packaging, no portal, no sync folder. The command you already use, finishing sooner.

What leaves my machine?

Only the inputs a job needs, encrypted in transit and at rest, deduplicated so nothing uploads twice. After the first run, an edit sends only the bytes you touched. Pin a project local‑only and nothing leaves at all.

What can it run today?

Anything you can run in a shell: Blender headless, ffmpeg, compilers, test suites. Next up are the Blender and FFmpeg buttons, where the app’s own render and export buttons boost automatically.

Do I need an internet connection?

For boosted runs, yes. Without one, your command simply runs locally like it always did. Ordinal is an accelerator, not a dependency; nothing in your project breaks when the network does.

Will the output be identical?

That is the bar. Jobs run on pinned versions of the same software you run locally, and every result is checked bit for bit before it lands in your folder. If a job can’t be reproduced exactly, it runs locally instead.

Which platforms does Ordinal support?

macOS on Apple silicon and Linux on x86‑64 and ARM. Windows is on the roadmap.

Why not just rent a cloud box?

You can, and then you become its part‑time admin: images, drivers, syncing, idle billing. Ordinal keeps the machine out of your life. You pay for finished work, and the fleet already remembers your project from last time.

What does it cost when I barely use it?

Nothing. Hobby has no monthly floor, so an idle month bills zero. A heavy week costs more than a quiet one, exactly as it should.

Is my work private?

Inputs and results are encrypted, stored deduplicated rather than under your name, and never used to train anything. We can’t see what you run, and you can wipe a project from the fleet whenever you like.
